# YOBO — Your Only Banking Option

## Project Overview
This repository showcases QA/SDET work on a sample **Account Aggregator based banking platform**
(similar in concept to services like Cred or Finvu). It is a portfolio project built with
dummy/sample data only — no real client names, production data, or confidential information are
included.

A consent-based Account Aggregator banking platform enabling users to securely aggregate, view,
and share their financial data across multiple banks and financial institutions in real-time.

## My Role
QA Engineer / SDET — responsible for test planning, manual and automated test coverage, API testing, defect tracking, and test reporting for this project.

## Tech Stack & Tools Used

## Types of Testing Performed
- Functional Testing
- API Testing
